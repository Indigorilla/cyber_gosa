# 출시 고사상

게임 출시 대박을 비는 사이버 고사 페이지. 빌드 과정 없는 정적 HTML 한 장입니다.

## GitHub Pages 배포

1. 새 저장소를 만들고 `index.html`, `.nojekyll` 을 루트에 올립니다.
2. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)` 로 지정합니다.
3. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

## 수정 포인트

- 기본 작품 이름: `index.html` 의 `id="gameName"` 의 `value`
- 소원 목록: 스크립트의 `WISHES`
- 점괘 문구: 스크립트의 `OMENS`
